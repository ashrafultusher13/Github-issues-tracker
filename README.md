# Github Issues Tracker

## Overview
A GitHub-like issue tracking system for managing project issues and tasks in an organized way.

## Technology Stack
- React.js
- Firebase (Auth & Firestore)
- Tailwind CSS
- JavaScript (ES6+)

## Main Features
- Create, edit, delete issues
- Track issue status (Open/In Progress/Closed)
- User authentication
- Real-time updates with Firebase

## Dependencies
- react-router-dom
- firebase
- react-icons
- react-toastify

## Setup & Run Locally
1. Clone the repo: `git clone [repo-link]`
2. Install dependencies: `npm install`
3. Start the app: `npm start`
